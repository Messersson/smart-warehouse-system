# 仓库手持扫码枪 App

## 服务地址

 App 登录页和“设置”页都可以配置服务地址，并支持一键“检测”。地址可以填根地址或 `/api` 地址，App 会自动补齐 `/api`。

常见部署填写方式：

- Android 模拟器调试：`http://10.0.2.2:18080/api`
- 手机连接本机 Docker 前端网关：`http://电脑局域网IP/api`
- 手机直连后端端口：`http://服务器IP:18080/api`
- 正式服务器推荐：`https://你的域名/api`

## 上服务器注意事项

- 手机必须能访问服务器端口。内网部署请开放 `80/443`，直连后端时开放 `18080`。
- 正式环境建议使用 HTTPS，并配置手机系统信任的证书。自签证书会被 Android 拒绝，App 的连接检测会提示证书不被信任。
- 当前前端 Nginx 已代理 `/api/` 到后端，手机端填 `http(s)://域名/api` 或 `http(s)://域名` 都可以。
- 如果只部署后端，不走前端 Nginx，也可以填后端地址，例如 `https://api.example.com/api`。
- Docker 部署时保持 `WMS_TOKEN_SECRET` 稳定，避免服务重启后已登录手机端 token 全部失效。

## 已接入能力

- 登录鉴权
- 扫码识别入库单、出库单、库位、商品条码库存
- 入库收货、上架、取件完成、延迟、拒收
- 出库拣货完成、发运
- 库存查询
- 盘点单查询、扫码定位明细、提交实盘数量、结束盘点、库存调整
- 最近扫码记录本机保存，重启 App 后仍可快速复查或再次查询
